## はじめに

[アプリ](https://aqucc.github.io/simple_ocr/) をブラウザで開くだけで使えます。インストール不要、画像は端末から外に出ません。初回の読み取り時に OCR エンジン（数十MB）を取得するため、最初だけ少し待ちます。

上部のタブで **撮影** と **カレンダー** を切り替えます。

## 撮影 → 読み取り

### 1. 画像を入力する

| ボタン | 動作 |
| --- | --- |
| カメラで撮影 | カメラ／写真ライブラリを開く |
| 画像を選択 | 端末内の画像ファイルを選ぶ |
| クリップボードから貼り付け | コピー済みの画像を貼り付け（`Ctrl` / `Cmd + V` でも可） |

### 2. モードと範囲を指定して読み取る

撮影・選択すると、**認識ダイアログ**（撮影／一覧タブのない専用画面）が開きます。ここで**認識モード**と**範囲**を選びます（撮影前ではなく読み取り直前に選べるので、同じ画像の読み比べも簡単）。閉じるには右上の **✕**（＝キャンセル）。

- **認識モード** — 上部左のトグル。型番・製造番号など半角英数字なら **英数字**、住所や品名など和文を含むなら **日本語**。選択は次回も記憶されます。
- **矩形モード**（既定）— 枠をドラッグで移動、四隅で拡縮。**読みたい行だけを囲む**と精度が上がります。
- **台形補正モード** — 斜めから撮った写真向け。四隅を独立に動かしてラベルの角に合わせると、正面から撮ったように補正します。

読み取りボタン（横1列。読取アクションは有色）:

- **キャンセル** — 認識をやめて戻る（画像は破棄）
- **指定範囲読取** — 枠内だけを認識（推奨）
- **全体読取** — 画像全体から文字行を自動検出して認識

### 3. 確認して保存

認識結果がテキストボックスに出ます（ボタンを横1列にしてテキスト欄を広く取っています）。

- そのまま編集できます。
- **単語フィルタ**（テキスト上部）— ノイズや記号の誤読を除くフィルタ。オフにすると生の認識結果に戻せます。
- 下部は横1列で **キャンセル**（保存せず戻る）／**再読取**（切り抜きへ戻ってやり直す）／**保存**（一覧に記録）。

## カレンダー・記録

**カレンダー**タブを開くと、月のカレンダーが1画面で出ます（記録がある日にバッジ）。

- **月の移動** — 上部の小さな **「← 前の月 / 次の月 →」**（中央に表示中の年月）。
- **日をタップ** → その日のリスト表示。上部は **「← 前の日 / 日付 / 次の日 →」** で、記録のある日を行き来できます（カレンダーへ戻るのはタブで）。**「この月の記録」**リンクで、表示中の月の記録を日毎にまとめて表示できます。
- 各記録は操作対象ごとにまとまっています:

| 位置 | 操作 | 動作 |
| --- | --- | --- |
| 写真（左） | タップ | 全画面拡大（どこかをタップで閉じる） |
| 写真の下 | 再読取 | その保存画像で認識をやり直す。**上書き保存**で同じ記録を更新（新しい記録は増えません）、キャンセルで元の記録へ戻る |
| テキスト下 | コピー | テキストをクリップボードへ |
| テキスト下 | 編集 | テキストをその場で修正して保存 |
| 右上 | ✕ | この記録を削除（確認あり） |

長いリストは縦スクロールします。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 古い画面が出る | 再読み込み、またはプライベートタブで開く（ヘッダ右の英数字が公開バージョン） |
| 貼り付けボタンが効かない | HTTP(S) 配信が必要（`file://` では不可）。`Ctrl`/`Cmd + V` を試す |
| 日本語の精度がいまひとつ | 読みたい行だけを枠で囲む／型番のみなら英数字モード |
| 斜めで読めない | 台形補正モードで四隅を合わせる |
| 保存記録が消えた | ブラウザのサイトデータ削除で消えます（端末内保存のため） |
