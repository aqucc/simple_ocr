# 機能一覧

このアプリでできることの一覧。各機能の挙動は [`FEATURES-DETAIL.md`](./FEATURES-DETAIL.md)、操作は [`MANUAL.md`](./MANUAL.md)、内部仕様は [`SPEC.md`](./SPEC.md)。

## 入力

| 機能 | 概要 |
| --- | --- |
| カメラ撮影 | 端末のカメラ／写真から取り込み |
| 画像選択 | ファイルから取り込み |
| クリップボード貼り付け | コピー画像を貼り付け（ボタン / `Ctrl`・`Cmd + V`） |

## 読み取り

| 機能 | 概要 |
| --- | --- |
| 認識ダイアログ | 撮影後、撮影/一覧タブのない専用画面（モーダル）で読み取り。✕ で閉じる |
| 認識モード | 認識画面で 英数字 / 日本語 を切替（記憶）。撮影前ではなく読み取り直前に選択 |
| 範囲指定（矩形） | 枠をドラッグして読む範囲を限定 |
| 台形補正 | 四隅を合わせて斜め撮影の歪みを補正 |
| 自動傾き補正 | ±12° の傾きを自動で水平化 |
| 全体読取 | 文字検出で各行を見つけて一括認識 |
| 単語フィルタ | 記号ノイズ・誤読を除去（オン/オフ切替） |

## 記録

| 機能 | 概要 |
| --- | --- |
| 保存 | 写真＋テキストを端末内に保存 |
| 表示切替 | ［カレンダー／月単位／日単位］をどこからでも相互に切替 |
| カレンダー | 月のカレンダー（記録日にバッジ）。「← 前の月／次の月 →」で月移動、日タップで日単位へ |
| 月単位 | 表示中の月の記録を日毎リストで表示。月移動あり、日付見出しタップで日単位へ |
| 日単位 | 1日分の記録。「← 前の日／次の日 →」で記録のある日を行き来（ナビは小さなリンク調） |
| 拡大表示 | サムネイルをタップして全画面 |
| テキスト編集 | 保存済みテキストをその場で修正 |
| 再読み取り | 保存画像で認識をやり直し、上書き保存で同じ記録を更新（新規追加しない） |
| コピー / 削除 | テキストのコピー、記録の削除 |

## 基盤

| 機能 | 概要 |
| --- | --- |
| 完全ローカル | OCR・保存ともブラウザ内で完結（画像を送信しない） |
| 省スペースUI | 撮影・認識・カレンダーは iPhone SE2 でも1画面（縦スクロール・バウンドなし）。月単位・日単位は上部ナビ固定で記録リストのみスクロール |
| PaddleOCR | 検出（DBNet）＋認識（PP-OCRv4 / PP-OCRv3 japan） |
| strict CSP | `unsafe-*` なし、インラインは sha256 許可 |
| 単一HTML | 依存は CDN と自己ホストのモデルのみ |
| PWA | ホーム画面に追加して全画面起動（manifest＋アイコン＋Service Worker） |
