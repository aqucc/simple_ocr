### エンジンの変遷

型番の実写ラベルに耐えるまで、認識エンジンは三段階で進化しました。

```
Tesseract.js  →  範囲指定 + PaddleOCR (rec)  →  PaddleOCR 全面（検出+認識）
   全画面OCRで          英数字を高精度エンジンへ。       DBNet 文字検出と日本語モデルを
   実写は壊滅            Tesseract は日本語だけ残置       追加し、Tesseract を全廃
```

---

## 2026-07-04 — 基盤と初期改善

- **PoC 作成** — Vue 3（render 関数のみ）＋ Tesseract.js、strict CSP。撮影→OCR→保存→日付別一覧＋カレンダーの一連。
- **GitHub Pages** — push で自動デプロイ。
- **日本語モード** — 英数字に加え `jpn` を選択可能に。
- **切り抜きGUI + PaddleOCR** — 実写の低精度に対し、範囲をドラッグ指定 → 英数字を PaddleOCR 認識モデル（rec-only）へ。
- **低信頼度の棄却** — 「存在しない文字を読む」問題に、スコア0.5未満の破棄・非ASCII除去。
- **単語フィルタ** — 認証マーク等の記号ノイズを、辞書／型番パターン／単位／略語のいずれかに該当するトークンだけ残して除去。
- **単語レベル分割** — `MADEINJAPAN` 潰れとバーコード隣接数字の無視を、単語ごとの個別認識で解決。
- **ライトボックス・再読み取り** — 保存画像の拡大表示と、撮影フローへの再投入。

## 2026-07-05 — UX と日本語、そして正面化

- **テキスト編集・ボタン再配置** — 保存済みテキストのインライン編集。操作を2段組化し誤タップを軽減。
- **`jpn+eng` 複合モデル** — 住所の埋め込み半角数字（`東京都千代田区1-2-3`）の無視・誤認を、言語データ自己ホスト＋複合認識と全角→半角正規化で解決。
- **説明のアコーディオン化** — 冗長な常時表示を折りたたみに。
- **台形補正・自動デスキュー** — 斜め撮影に対し、四隅ドラッグの射影変換と ±12° の自動傾き補正（いずれも純JS、OpenCV 不使用）。

## 2026-07-06 — Tesseract 全廃と運用

- **PaddleOCR 一本化** — DBNet 文字検出（全画面読み）と PP-OCRv3 japan 認識モデルを追加し、Tesseract・tessdata・旧前処理を削除。
- **バージョン表示** — 旧キャッシュ判別のため、デプロイ版（コミットID）をヘッダに表示。
- **デプロイ自動リトライ** — Pages バックエンドの断続的な即時失敗に、ワークフロー内で再試行。

## 2026-07-11 — 精度の回帰修正と認識フロー分離

- **ブロック解析方式を撤去** — 全体読み取りの方式トグルを廃止し、実績のある DBNet 検出方式のみへ戻した。方式の永続設定が低精度側に固定され「認識精度が落ちた」問題の解消。
- **認識機能を独立フロー化（B案）** — 撮影／一覧から遷移する独立した認識フローに再設計。撮影→認識は新規保存、一覧→再読み取りは**上書き保存**で同一レコードを更新（再認識のたびにカレンダーへ重複登録される問題を解消）。キャンセル先も入口に応じて撮影／一覧へ分岐。
- **認識モード選択を認識画面へ移動** — 英数字／日本語の選択を撮影前ではなく切り抜き画面（読み取り直前）に配置。同じ画像の読み比べが容易に。
- **iPhone SE2 no-scroll レイアウト** — 撮影・認識（切り抜き／結果）画面を SE2 でも縦スクロール不要に。切り抜き画像はステージを実寸化してオーバーレイの座標対応を保ちつつ高さを上限化、結果はテキスト欄が余白を吸収する flex 構成に。カレンダーも1画面に収め、当日レコード一覧のみスクロール。検証に SE2 no-scroll ゲートを追加。
- **認識機能をモーダル化＋スクロール抑止** — 認識機能を撮影／一覧タブを持たない全画面モーダル（ダイアログ、✕で閉じる）に。アプリを固定高シェル化し `overscroll-behavior:none` で iOS のラバーバンド（ふよふよ）を解消。スクロールは記録リストとモーダル本文のみ。
- **読み取りボタンを横1列に** — 指定範囲 / 全体読取 / やり直す（キャンセル）を1行に整列。
- **一覧をカレンダー中心に再構成** — 一覧はまずカレンダーのみ。日をタップでその日のリスト（「‹ カレンダー」「日毎リストのみ」）、全日表示も可能に。
