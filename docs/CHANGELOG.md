# 開発経緯ログ

このアプリがどう作られ、どんな課題をどう解決してきたかの記録です。現時点の仕様は [SPEC.md](./SPEC.md)、使い方は [../README.md](../README.md) を参照してください。

日付は開発日（2026-07-04〜07-06）。要約は各コミットに対応します（デプロイ再試行などの雑多なコミットは省略）。

## 2026-07-04

- **単一HTMLのOCR PoC を作成** (`d922f60`): Vue 3（ランタイム限定・render 関数のみ）＋ Tesseract.js（WASM）で、撮影→OCR→編集→IndexedDB 保存→日付別一覧＋月カレンダーの一連の流れを実装。strict CSP（`unsafe-*` なし、インラインは sha256 ハッシュ許可）で開始。
- **GitHub Pages デプロイ用ワークフローを追加** (`d32bb7e`): 以後、対象ブランチへの push で自動デプロイ。
- **日本語モード（`jpn`）を追加** (`127facb`): 英数字（`eng`）に加え日本語を選択可能に。当初は言語データが別 npm パッケージのため `jpn` 単体。
- **切り抜きGUI＋PaddleOCR（PP-OCRv4）を導入** (`f095f4d`): 実写ラベルで Tesseract の全画面OCRが低精度だった問題に対し、(1) 読み取り範囲をドラッグ指定する切り抜きUI、(2) 英数字×範囲指定を PaddleOCR 認識モデル（onnxruntime-web）に置換。「人間の範囲指定＝文字検出」とみなし DBNet を省く rec-only 方式。
- **低信頼度の棄却でノイズ幻字を抑制** (`2d460d8`): 「存在しない文字を読む」問題に対し、PaddleOCR は行スコア0.5未満を破棄・英数字は非ASCII除去、Tesseract 経路は大域Otsu→局所適応二値化＋デスペックル＋単語信頼度フィルタに変更。
- **単語フィルタ（ハイブリッド分類器）を追加** (`ffb0a04`): 認証マーク（丸囲みR・角囲み検印など）の中の文字が記号ノイズとして残る問題に対し、「英単語辞書／型番パターン／単位／略語ホワイトリスト」のいずれかに該当するトークンだけ残す方式。型番が辞書に無くても消えないのが要点。英単語辞書は `word-list`（約27万語）を遅延ロード。
- **単語レベルの自動分割＋バーコード隣接数字の修正** (`1f4c61a`): 「MADE IN JAPAN」が「MADEINJAPAN」に潰れる／バーコード横の数字が無視される問題に対し、各行を列方向のインク・プロファイルで単語ごとに切り出して個別認識。行検出のしきい値もバーコードの縞に釣り上げられないよう改良。EAN先頭1桁の例外も追加。
- **保存画像のライトボックス表示と再読み取りを追加** (`8b55ef1`): サムネイルのタップで全画面拡大、保存済み画像を撮影フローに戻して再OCR。

## 2026-07-05

- **記録テキストの編集機能とボタン配置の見直し** (`bb80c4a`): 「押しにくい」というフィードバックに対し、記録カードの操作を2段組化（削除は危険色で分離）、結果画面は「保存する」を単独全幅に。保存済みテキストのインライン編集（1件ずつ）も追加。
- **tessdata 自己ホスト＋ `jpn+eng` 複合モデル** (`9b84f77`): 住所の漢字に挟まれた半角数字（例: `東京都千代田区1-2-3`）が無視・誤認識される問題に対し、言語データをリポジトリ同梱・同一オリジン配信にして Tesseract の `jpn+eng` を解禁。全角→半角正規化も追加。
- **説明文をアコーディオンに収納** (`7b05b03`): 常時表示の説明が冗長という指摘に対し、認識モードの詳細と撮影のコツを `<details>` で折りたたみ。
- **デプロイの一時失敗への耐性強化** (`00f8d73`): GitHub Pages バックエンドが時々即時失敗を返すため、リトライ許容回数・タイムアウトを拡大。
- **台形補正（射影変換）と自動傾き補正を追加** (`6829fb6`): 正面から撮っていない写真への対応。切り抜きに「台形補正」モード（4点独立ドラッグ＋角の自動サジェスト）を追加し、矩形モードでは±12°の自動デスキュー。ホモグラフィ・デスキューとも純JS実装（OpenCV不使用）。
- **Tesseract を全廃し PaddleOCR + ONNX Runtime Web に一本化** (`dc69c79`): 「Tesseract は古い、廃止したい」という要望に対し、(1) 英数字の全画面読みに DBNet 文字検出を実装、(2) 日本語認識を PP-OCRv3 japan モデル（ONNX、Apache-2.0、自己ホスト）に置換。Tesseract 本体・ワーカー・tessdata・二値化前処理などを削除。OpenCV.js は「既存の純JS前処理で足りる／+8MBは不要」と判断し不採用。

## 2026-07-06

- **ヘッダにデプロイ版（コミットSHA）を表示** (`58fd277`): 「まだ Tesseract と出る」＝ブラウザキャッシュに旧版が残る問題を可視化するため、デプロイ時にコミットIDを埋め込んで表示。
- **デプロイステップ自体を自動リトライ化** (`e64eb07`): Pages バックエンドの高頻度な即時失敗に対し、失敗時は60秒待って同一アーティファクトで自動再デプロイ。
