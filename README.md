# ラベルOCR

**製品ラベルの型番・製造番号を、ブラウザだけで読み取る。**
撮る → 囲む → 読み取る → 保存。画像は端末から出ません。

[**▸ アプリを開く**](https://aqucc.github.io/simple_ocr/)

`PaddleOCR + ONNX Runtime (WebAssembly)` ・ `Vue 3` ・ `strict CSP` ・ 単一HTML

</div>

---

## 特長

- **完全ローカル** — OCR も保存もブラウザ内で完結。サーバーへ画像を送りません。
- **型番に強い** — 範囲指定 × 単語フィルタで、記号ノイズやバーコード隣接の数字も拾う。
- **斜めでも読める** — 自動の傾き補正と、四隅を合わせる台形補正。
- **記録が残る** — 写真とテキストを日付ごとに保存し、カレンダーで振り返る。

## 使い方

1. **入力** — 撮影 / 画像選択 / クリップボード貼り付け
2. **範囲指定** — モード（英数字 / 日本語）を選び、読みたい行を枠で囲む
3. **保存** — 認識結果を確認・編集して保存

> 読みたい行だけを枠で囲むと精度が上がります。型番など英数字だけなら「英数字」モードが最も安定します。

## メモ

- OCR には通信が必要です（初回にモデルを取得、以後キャッシュ）。
- クリップボード貼り付けは HTTP(S) 配信時のみ。撮影・画像選択は `file://` でも可。
- ヘッダのタイトル横の英数字は公開バージョン。古いままなら再読み込み（またはプライベートタブ）で最新版に。

## 開発

単一 `index.html`（Vue 3 ランタイム限定 / `h()` のみ / strict CSP）。

```sh
node tools/update_csp_hash.mjs   # インライン script/style 編集後に CSP ハッシュ再生成
node tools/verify.mjs            # Playwright + Chromium で E2E テスト
```
