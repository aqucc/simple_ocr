# ラベルOCR（ブラウザ完結・単一HTML）

家電などの製品ラベル（型番・製造番号のシール）をスマホで撮影し、**ブラウザ内でローカルOCR**して文字を抽出・編集し、写真とテキストを保存できる PoC アプリです。サーバーへ画像を送信せず、すべて 1 つの `index.html` で動作します。

- OCR エンジンは **PaddleOCR + ONNX Runtime Web（WebAssembly）**。
- UI は日本語。iPhone SE3 の Safari と、デスクトップの主要ブラウザで動作します。
- 保存した記録は保存日でグループ化して一覧表示し、月カレンダーで日付を絞り込めます。

## 使い方

1. **撮影・入力**: 「カメラで撮影」「画像を選択」「クリップボードから貼り付け」（`Ctrl/Cmd+V` も可）のいずれかで画像を読み込みます。
2. **認識モードを選ぶ**（撮影ボタンの上）:
   - **英数字(型番向け)**（既定）— 型番・製造番号・シリアルなど半角英数字向け。最も高精度。
   - **日本語+英数字** — 住所・品名など和文を含むラベル向け。
3. **範囲を指定して読み取る**: 画像上の枠をドラッグ（四隅で拡縮）して**読みたい行だけを囲み**、「この範囲を読み取る」。枠を使わず「全体を読み取る」も選べます。
   - 斜めから撮った写真は「**台形補正**」に切り替え、四隅をラベルの角に合わせると歪みを補正できます（軽い傾きは自動補正されます）。
4. **確認して保存**: 認識テキストを必要に応じて編集し、「保存する」。
5. **一覧・カレンダー**: 「一覧」タブで保存日ごとに確認。サムネイルのタップで拡大、テキストの編集、画像からの再読み取り、コピー、削除ができます。

> **精度を上げるコツ**: 読みたい行だけを枠で囲む／ラベルを大きく・明るく・なるべく正面から撮る。型番など英数字だけを読むなら「英数字」モードが最も安定します。

## 主な機能

- 撮影／画像選択／クリップボード貼り付けの3通りの入力
- 読み取り範囲の指定（矩形／台形補正）と自動傾き補正
- ノイズ・認証マーク等の誤読を抑える単語フィルタ（結果画面で ON/OFF 切替可）
- 認識テキストの編集、保存済み記録の再編集・再読み取り
- 写真＋テキストの保存（IndexedDB）、日付別一覧、月カレンダー、拡大表示、コピー、削除

## 動作環境・注意

- **OCR にはネットワーク接続が必要**です（初回に OCR エンジン・モデルを取得。以後はブラウザにキャッシュ）。
- **クリップボード貼り付け**は HTTP(S) 配信が前提（`file://` では不可）。カメラ撮影・画像選択のみなら `file://` でも開けます。
- 画像はサーバーに送信されず、保存データもすべて端末内（IndexedDB）に留まります。
- ブラウザのサイトデータを消すと保存記録も消えます。
- ヘッダのタイトル横に小さく表示される英数字は、公開中のバージョン（デプロイ時のコミットID）です。古い版が表示される場合はブラウザのキャッシュが残っています（タブを開き直す／プライベートタブで開くと最新版になります）。

## 開発者向け

- アプリ本体は `index.html` の1ファイル（Vue 3 ランタイム限定・`h()` render 関数のみ）。厳格な CSP（`unsafe-*` なし、インラインは sha256 ハッシュで許可）。
- `index.html` のインライン `<script>`/`<style>` を編集したら `node tools/update_csp_hash.mjs` で CSP ハッシュを再生成。
- 自動テスト（Playwright + Chromium）: `node tools/verify.mjs`。
- 詳細は [docs/SPEC.md](docs/SPEC.md) を参照。
